# Модель и View

Модель описывает состояние и способы его изменения. View отображает props и
сообщает о действиях пользователя через callbacks. Holo связывает эти две части.

```text
пользователь → callback → Action → Store.set
                                      │
                          зависимые атомы и проекции
                                      │
View ← обычные props ← Holo.read ← уведомление подписки
```

Если нужна маршрутизация события с guard и выборкой состояния, вставьте
`Event → Bond → Action` между callback и записью. Для простого счётчика прямого
действия достаточно.

## Определение атома и значение — разные вещи

`WritableAtom<T>` и `Atom<T>` имеют стабильную идентичность. Клонирование handle
сохраняет её. `Store` содержит значения и кеши для этих определений.

```rust
use jotai::{Store, atom};

let count = atom(0);
let same_count = count.clone();
assert!(count == same_count);

let left = Store::new();
let right = Store::new();
left.set(&count, 10);
assert_eq!(left.get(&same_count), 10);
assert_eq!(right.get(&count), 0);
```

`Store::clone()` обращается к тому же хранилищу. Для независимых значений создайте
новый `Store::new()`. Для независимых моделей в одном Store вызовите фабрику модели
повторно: новые атомы получат другие идентичности.

## Модель — обычная структура

Специальный базовый класс или регистрация не нужны. Возвращайте из фабрики атомы,
действия и соединения. Примеры полных моделей есть в [корзине](../recipes/cart.md)
и [редакторе профиля](../recipes/profile.md).

В текущей реализации нет автоматического registry по ключу. Если двум виджетам
нужен один экземпляр модели, передайте им ту же модель или её `Rc`.

## Проекция и рендер

Вычисление `prism` может повториться после изменения исходного объекта.
Если выбранное значение осталось равным по `PartialEq`, подписчик не получит
уведомления. Отслеживаются чтения атомов, а не доступ к отдельным полям структуры.

Holo подписывает соединяющий компонент только на перечисленные `read`-источники.
Yew всё ещё может перерисовать компонент из-за локального состояния, новых props
или context. Holo не гарантирует отсутствие всех других рендеров.
