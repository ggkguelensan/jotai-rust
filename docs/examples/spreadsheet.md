## Листы с CSV-данными

В книге также доступны два полных набора: **Penguins** — 344 записи × 8 столбцов,
**Titanic** — 891 запись × 15 столбцов. Первая строка каждого листа содержит
заголовки, поэтому размеры листов — 345 × 8 и 892 × 15.

Переключите вкладку внизу таблицы. Например, в Penguins перейдите к `H345`,
а в Titanic — к `O892`, чтобы увидеть последнюю строку. Пустые поля CSV остаются
пустыми ячейками; `NA` из Penguins сохраняется как исходный текст.
Исходный ввод сохраняет точность CSV, а числовое отображение округляется до двух знаков.

Листы добавляются и к ранее сохранённой книге. Существующие листы, активный выбор,
переименования и изменения данных сохраняются. Повторное открытие не создаёт
дубликаты. «Сбросить лист» на Penguins/Titanic восстанавливает соответствующий CSV.
Если в книге уже достигнут предел числа листов, новые листы не добавляются.

CSV встроены в приложение и разбираются целиком с проверкой ограничений до
создания атомов; сетевой загрузки при открытии нет. Пользовательского выбора
CSV-файла в интерфейсе пока нет. Источники и лицензии указаны в
[data/SOURCES.md](https://github.com/ggkguelensan/jotai-rust/blob/main/examples/yew-spreadsheet/data/SOURCES.md).

## Попробуйте

| Действие | Что произойдёт |
| --- | --- |
| Двойной клик по B1 → `20` → Enter | D1 станет 1600, итог D5 — 4840 |
| Выберите D1 | Строка формул покажет `=B1*C1` |
| Enter или F2 в выбранной ячейке | Откроется редактор; Escape отменит черновик |
| Tab / Shift+Tab | Сохранит ввод и перейдёт к следующей/предыдущей ячейке |
| Стрелки вне режима редактирования | Переместят выбор; окно следует за ним |
| Перейдите к AA90 и запишите `7` | Значение сохранится за пределами начального окна |
| Вернитесь к A1 и введите `=AA90*3` | Формула покажет 21, хотя AA90 не видна |
| Уменьшите число строк до 50, затем верните 100 | A1 покажет `#REF!`, затем снова 21; скрытые данные сохранятся |
| Переключитесь на «Черновик» | Откроется независимый лист; выбор и окно первого сохранятся |
| Двойной клик по вкладке | Можно переименовать лист; `+` создаёт новый |

После надписи «Сохранено локально» перезагрузите страницу: книга восстановится.
Сброс действует только на текущий лист. На узком экране окно содержит два столбца,
на широком — четыре; показываются восемь строк.

## Как это связано с Jotai и Holo

У каждой ячейки собственная цепочка атомов:

```text
input: WritableAtom<String>
  └── ion(parse) → expression: Atom<Result<Expr, Error>>
        └── derived → value: Atom<Value>
                          ↑
                    значения ссылочных ячеек
```

`ion` преобразует введённую строку в синтаксическое дерево. Вычисление формулы
читает другие value-атомы через `get`: ядро отслеживает зависимости и кеширует
общие промежуточные результаты. Изменение формулы заменяет её зависимости.
Непрочитанные результаты остаются ленивыми. Валидация топологии после записи
проверяет циклы до того, как value-атомы начнут читать друг друга.

<<< @/../examples/yew-spreadsheet/src/model.rs#spreadsheet-cell

Каждая видимая ячейка имеет Holo-привязку. View получает строки, значения,
состояние редактора и callback команды. При перемещении окна физические позиции
ячеек сохраняют ключи, а адреса и подписки меняются.

<<< @/../examples/yew-spreadsheet/src/ui.rs#spreadsheet-binding

Модель книги владеет листами; модель листа — атомами ячеек и редактора.
Отдельная подписка сохраняет подтверждённые изменения через 250 мс бездействия,
при переключении листа — сразу. Ошибка сохранения отображается с кнопкой повтора.
Изменение черновика без подтверждения не сохраняется как новое значение ячейки.

## Формулы и ошибки

Поддерживаются числа, ссылки (`B1`, `AA90`), скобки, унарные знаки,
`+`, `-`, `*`, `/`, `SUM` с аргументами и прямоугольными диапазонами.
Регистр не важен; десятичный разделитель в формулах — точка.
`SUM` игнорирует текст и пустые ячейки; арифметика считает пустую ячейку нулём.
Текст в арифметическом выражении даёт `#VALUE!`.

| Ошибка | Причина |
| --- | --- |
| `#REF!` | Ссылка за границами листа или недопустимый адрес |
| `#CYCLE!` | Циклическая ссылка; исправление формулы восстанавливает расчёт |
| `#DIV/0!` | Деление на ноль |
| `#VALUE!` | Несовместимое значение |
| `#NUM!` | Нефинитный числовой результат |
| `#FORMULA!` | Неподдерживаемый синтаксис |
| `#LIMIT!` | Превышен предел диапазона/вычисления или глубины ссылок |

Лист ограничен 1000 строками и 1000 столбцами. Формула — 512 байт,
диапазон — 2048 ячеек, бюджет одной формулы — 2048 шагов, глубина ссылок — 128.
Для текста ввода действует ограничение 512 символов. Это учебный движок
с `f64`, а не реализация формата Excel. Нет `.xlsx`, ссылок между листами,
выделения диапазонов и вставки CSV из буфера обмена.

## Отличия от TypeScript-примера

Данные стартового бюджета взяты из оригинального JSON; его MIT-лицензия сохранена
в `examples/yew-spreadsheet/UPSTREAM-LICENSE`.
В Rust-версии локальное сохранение использует синхронный `localStorage`, а не
IndexedDB. Формулы, листы, выбор и окно восстанавливаются из snapshot; результаты
вычисляются заново. Нет retention/eviction registry, async leases хранения
и интерактивной карты кода из оригинальной документации. Все листы и посещённые
атомы остаются в памяти до закрытия книги.

Сохранение привязано к origin iframe: отдельная вкладка и документация разделяют
его только при совпадении схемы, хоста и порта. Rust-пример использует собственный
ключ и не читает сохранения TypeScript-версии.

## Запуск и исходники

```sh
export PATH="$HOME/.cargo/bin:$PATH"
cd examples/yew-spreadsheet
trunk serve --address 127.0.0.1 --port 8081
```

Откройте <http://127.0.0.1:8081>.
Для встраивания в документацию запустите `npm run docs:dev` из корня проекта.

```text
examples/yew-spreadsheet/
├── gift-budget.json     стартовые данные оригинального примера
├── src/
│   ├── coordinates.rs   адреса и размеры
│   ├── formulas.rs      парсер и вычислитель
│   ├── model.rs         книга, листы, ячейки и редактор
│   └── ui.rs            Holo-привязки, Yew Views и локальное сохранение
└── tests/workbook.rs    вычисления, зависимости, циклы и snapshot
```
